# 角色工作台一键美化

2026-10-10，沿用 0.1.0 preview；正式发行及干净 Windows 验收仍另行进行。

## 使用方式

画布工具栏提供“一键美化”：按对白连接结构重新安排卡片，使用实际卡片尺寸保留横向走线通道和纵向间距，并适配整个画布。汇合节点放在前置分支之后，循环节点单独展开，未连接卡片放在下方。

自动连线统一分配通道，使用避开卡片的折线路径，包含条件开场、长跳转、循环和回跳。通道选择惩罚与已分配路径贴近或重叠的长平行段，允许短暂的横向交叉；同一卡片的多个入口在端口前分开接近，只共享最后的短端口段。使用 React Flow 的实际端口边缘坐标，几何不变时共享派生缓存。

现有手动走线仍然可用；点击美化时清除手动控制点、恢复自动走线，保留连线颜色。新增连线标识暂不实施。

保存前可以“撤销美化”，准确恢复此前的位置、手动控制点以及未保存状态。后续编辑或保存会结束本次快捷撤销；保存后继续使用原有全局撤销与重做。未保存导航保护不变。

## 数据与兼容性

- 只修改既有 `editor.dialogue_layouts` 和 `editor.dialogue_edges`，没有新增项目版本、后端契约或迁移。
- 不改变节点／选项 ID、作者顺序、正文、跳转目标、条件、效果、开场规则、人物或出场绑定。
- 沿用原 `put_dialogue_layout` 保存事务及撤销日志，作者内容和布局元数据保持分离。
- 手动把卡片叠在端口上时可能没有可行的自动路径，此时保留原曲线回退；美化会重新分开卡片。手动控制点也可以改变走线，应再次美化或恢复自动走线。
- 不调用模型，不消耗生成配额。

## 连线选中反馈

选中连线使用亮色粗线、保留原标记颜色的光晕与亮色箭头，已有条件标签同步突出。高亮线宽不随画布缩小而减弱；点击空白恢复原样。此状态不写入工程或触发未保存提示。构建和真实点击／取消选择检查通过，检查期间用户工程哈希保持不变。

## 转折与端口方向

自动路径比较完整的出线、通道和入线，禁止立即折返或钩状入线。窄间距使用较短的端口引线；带方向与转折代价的网格寻路处理需要绕行的连接。正常向前分支优先减少反向横移和多余折弯，回跳从卡片外侧绕行。圆角只用于实际转角，直线或旧折返点不再绘制小圆钩。

美化根据每一列的出线数量预留通道宽度，仍然只保存原布局字段。旧布局的自动走线会立即使用新算法；想应用更宽的卡片排版，需要再点击一次“一键美化”。

实际用户对白的只读检查与独立副本的一键美化检查中，10 条 SVG 连线均未发现折返钩子或穿卡。副本的美化、撤销及保存／刷新检查通过，保存前后叙事内容及内容版本保持一致。

## 开场和结束卡片拖动（2026-10-11）

开场规则和结束节点可直接拖动，连接端点和自动避障随位置更新。点击“保存编排”保存布局；未保存导航保护、放弃修改和保存后的全局撤销／重做沿用现有机制。一键美化会一起重排这两个节点，撤销美化恢复原位置。

在既有 `editor.dialogue_layouts` 中允许两个专用布局键 `__entry`、`__end`；作者节点 ID 的校验保持原样。没有这两个键的旧项目继续使用原默认布局，无需迁移。修改对白内容时保留专用位置、移除已删除的对白节点位置；删除整个对白时清理所有位置。项目协议版本仍为 2，模型作者指纹和预演语义不变。Schema、中英文 Skill 资源和帮助已同步。
