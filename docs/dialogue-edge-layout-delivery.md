# 对白连线颜色与走线

点击对白连线打开画布内的标记面板：六种预设色、自定义颜色和默认颜色。选中连线后拖动圆形控制点即可改变路径；双击连线在最近的一段路径上插入控制点，双击控制点移除，方向键可微调，支持最多 8 个点。恢复自动走线移除自定义点但保留颜色。

端点继续绑定原有入口与玩家选项，移动对白卡片后连线端点跟随；控制点使用画布坐标。自定义颜色优先显示，预演选择仍可通过线条动画和粗细提示。颜色没有剧情条件或效果含义。

`editor.dialogue_edges` 按对白 ID、连线 ID 保存颜色和控制点。与卡片坐标一起由 `put_dialogue_layout` 原子提交，加入未保存编排的保存、放弃和跳转保护。旧项目默认空；旧客户端只提交 positions 不覆盖连线设置。删除对白或选项会清理对应布局。条件入口修改或重排后清除其旧标记，避免按索引把标记套到另一条入口。
