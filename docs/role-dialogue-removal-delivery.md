# 角色工作台对白移除与删除

出场与对白目录的每个已保存条目增加「…」，支持右键和键盘菜单导航。出场中的条目提供「移除本次出场关联」和「删除对白」，通用与未关联条目提供删除。未保存的新对白先保存后再操作，已有编辑通过共享保存／放弃／取消保护后才打开确认窗口。

移除关联只更改当前出场；对白内容及其他出场引用保留。删除对白会同时清理该对白的全部有效出场引用，删除正文、拓扑及布局；确认窗口列出受影响出场。草稿、生成记录、预演输入及其他剧情资料的引用仍然阻止删除，不能静默破坏不可变记录。历史试玩文本快照保留。操作使用同一作者事务和撤销日志，检查对白内容及关联集合是否自确认时发生变化，并保留后来修改的其他字段。

新增 Appearance.inherit_dialogues，默认 true 且序列化时省略；旧空 dialogue_ids 保持人物默认对白语义。主动移除后设置 false，空列表代表本次出场没有对白，不重新继承其他对白。关卡目录、预演、NPC 组、草稿采用、模板复用、创建对白及正式导出同步尊重该标记，新的明确关联仍通过 dialogue_ids 保存。新版本读旧文件无需迁移，默认字段不会改变旧生成基线的作者哈希。

验证覆盖最后一项移除、默认关联转显式列表、跨出场删除、内容和引用冲突、引用阻止、旧哈希与序列化、预演阻止、导出、模板、撤销。独立浏览器项目验证取消、两个出场删除、撤销、空出场清除旧画布、其他出场保留，以及未保存编辑的取消与放弃。桌面和手机入口／确认均可达。
