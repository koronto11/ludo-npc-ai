# 人物创建入口优化

人物总览和左侧角色/背景居民的新建入口使用独立人物表单，不再显示对象类型。四项字段：姓名、身份/职责、角色定位、人物简介。背景居民入口默认背景角色，其他人物入口默认支线角色。保留明确命名的通用故事对象窗口用于其他入口。

创建通过既有 Python 原子命令提交人物和关系画布显示节点，基于最新项目保留已有画布节点及连线。简介写入 description，与人物故事分开；不创建场景出场、对白、地点或阵营。成功后留在人物总览并选中新人物。关闭未保存输入提供保存、不保存和继续编辑；失败保留输入，固定 ID 防止重试重复创建。

验证：前端 148 / 148 通过，构建通过，中英文表单可见；独立 4186 测试项目实际创建、保存后刷新读回成功。关闭后继续编辑保留输入，背景居民默认定位正确。读取独立项目文件确认仅新增一个人物，简介完整，故事为空，地点/阵营/对白/关卡均未创建。

用户项目只刷新并打开空白创建窗口，没有新增测试人物或修改故事数据。截图 `character-create-preview.png`。UI 文案及中英文帮助同步。未调用真实模型；本轮未修改后端合同。
