# 角色工作台拖动闪烁修复

受控 React Flow 节点此前只保留位置，忽略 `dimensions` 变更。每次拖动或编辑重建节点时，当前版本 React Flow 的 `adoptUserNodes` 会清除缺失的 `measured`，节点先变成隐藏，再重新测量显示，造成卡片及连线闪烁。

现在将尺寸和拖动标记保存在工作台临时状态中，每次节点更新均带回画布；重复尺寸通知不触发额外状态更新。切换对白或放弃草稿时重置临时状态。这些测量信息不进入本地项目文件，保存布局仍只保存对白节点坐标。

标题行预留“放弃未保存编排”按钮高度，避免首次拖动由已保存切换到未保存时挤动画布。

验证：

- 新增 3 项回归测试，使用当前安装的 React Flow 节点初始化逻辑验证 30 个连续拖动帧始终保有尺寸，并覆盖文本高度变化、重复通知和拖动结束。
- 全部 55 项前端测试通过，生产构建和 `git diff --check` 通过。
- 在独立浏览器页实际多次拖动，所有 5 个节点保持可见，连线跟随；拖动后玩家选项仍可进入编辑，浏览器无错误或警告。
- 首次拖动前后画布边界均为 x=408、y=332.796875、width=872、height=261.203125，未保存按钮不再改变画布尺寸。靠近边缘时 React Flow 原有自动平移仍保留。
- 验证页上的测试拖动全部放弃，没有保存到用户的体验项目。
