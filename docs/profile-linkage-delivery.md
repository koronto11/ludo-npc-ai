# 人物档案与对白联动

本批集中补齐人物手动设定，以及出场安排变化后的对白条件检查。数据仍保存在用户本地工程 JSON，不新增云存储，也不自动调用模型。

## 使用入口

- 人物总览：选择人物 → 编辑人物档案。人物卡片菜单、关系画布卡片菜单与人物设置也使用同一个编辑器。
- 默认编辑姓名、身份、简介与故事；展开其他设定后编辑性格、口吻、目标、行为底线和待定设定。
- 每个字段可勾选保护，阻止模型草稿覆盖；作者仍可手动修改。关闭未保存表单时提供保存、不保存、取消，保存失败会保留输入。
- 关卡画布：对白联动检查。也可选中人物出场后只检查这次出场的对白。

## 联动语义

选择“跟随本次出场”后，Python 在预演时读取该出场最新的场景、时间和出场条件。拖动人物、NPC 组或锚点即可改变可用范围。原对白选项、效果、受伤、任务与认知条件保留。新生成的场景人物对白默认采用这类出场引用。

旧对白保持独立条件，检查不会自动修改工程。可识别的当前完整场景/时间约束，以及带有已采用草稿来源的旧生成范围，在主动启用联动时被替换；无法确认来源的作者自定义约束会保留，可能仍需进入编排手动调整。检查仅覆盖必须满足的明确场景、时间与出场引用，不分析自然语言台词或推断复杂任一/取反条件。

共用对白启用联动时先复制为本次出场专用对白，只调整所选出场的关联，其他出场使用原对白。解除联动会把当前场景、时间和出场条件固化为独立条件。删除被联动引用的出场或关卡须先解除引用；服务端拒绝悬空引用和循环出场条件。
