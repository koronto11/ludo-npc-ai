# 角色工作台：出场与对白

左侧合并为单一“出场与对白”层级：每次出场独立显示关卡、场景、时间范围及有效对白，提供新建、关联已有和定位关卡入口。点击对白同时切换出场、编辑流程、顶部路径及预演地点/开始时间；场景为空时显示新建/关联入口，不回退到别的场景对白。

通用和未关联分区可折叠，空分区默认收起。分区根据现有对白引用推导，不新增数据库或更改保存格式：空 dialogue_ids 保持使用人物默认对白，列表明确标注；没有显式出场引用、但作为默认对白被使用的角色对白，以及尚无出场人物的对白，显示在通用区；有出场但未被任何出场使用的角色对白显示在未关联区。相同地点的多次出场保持独立。

新建场景对白在保存时关联指定出场，放弃后恢复该出场原有对白；暂不关联的对白单独保存。关联已有对白保留原有有效对白并追加引用，不复制对白或人物；禁止关联其他人物所属对白。共享对白显示使用次数。跨场景、跨对白及新建操作使用顶部未保存选择面板。

验证：52 项 Node 测试通过（含 8 项场景层级与引用回归）；前端构建和 diff 检查通过。浏览器验证了篝火/医帐选择同步、医帐开始时间 27 与地点、未保存切换取消保留输入、从场景新建及放弃恢复、引用复用及完成后选中所选对白、场景新建持久化、未关联对白收纳。保存验证使用独立项目副本，主体验项目没有测试对白，人物数量保持不变。
