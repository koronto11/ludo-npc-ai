# 人物总览删除

人物详情和卡片右键菜单提供“删除人物 · Del”；勾选多人后显示“删除所选 · Del”，跨页选择仍参与同一次删除。人物总览中的 Delete 键先打开确认弹窗，有勾选时使用勾选集合，否则使用当前选中人物。文本输入、其他弹窗、菜单、组合键、输入法组合和按键重复不会触发删除。

复用资料库的类型化引用检查和删除命令，不改变项目格式。出场、对白、关系、事件、规则、文本、草稿及生成记录引用会阻止删除，确认页提供关联跳转。删除不级联清除这些资料；历史试玩快照保留。一次最多 499 人，确认时再次检查最新档案、引用和初始状态，任一失败则整批不提交。只清除被删人物的初始状态，其他人物与变量使用提交时最新值。

删除接入共享作者撤销，恢复档案、初始状态、备注与画布引用。即时“撤销删除”仅针对刚完成且尚未有后续修改的删除；后续操作使用顶部撤销依次恢复。生成运行中和未保存编辑/预演输入需要先完成或保存。

验证：205 项前端测试通过，生产构建与中英文帮助同步检查通过。独立本地工程包含 73 人，用真实浏览器验证单人删除/取消/撤销、备注恢复、跨页批量删除/撤销、复选框 Del、输入保护、引用拦截、右键入口、720px 窄屏及英文确认。未对用户当前工程执行删除，未调用模型。
