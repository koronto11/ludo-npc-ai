# 世界底稿编辑窗口 · 第一版

2026-10-07。使用用户选定的 `world-editor-design-reference.png`：左侧四个分区，右侧集中编辑，底部固定保存栏。保持现有工作台背景与世界—关卡层级。

## 行为

- 默认打开故事前提。基础信息、故事前提、已确认规则、写作风格共享同一份未保存输入；切换分区保留文本及编辑状态。
- 故事前提和写作风格为大幅多行编辑区，显示 Unicode 字符数，支持放大窗口。
- 规则逐条编辑、添加、移除；单条规则允许换行。批量粘贴按每行一条解析，并忽略空行。未点击“添加到规则列表”的批量输入也会随保存提交。
- 名称不能为空。保持既有后端上限：正文、风格和每条规则各 30,000 字符，规则最多 500 条。超限会保留输入并定位相关分区。
- 固定底栏显示保存状态、取消和保存并关闭。关闭未保存内容提供保存、不保存和继续编辑。保存失败或其他页面修改相同字段时保留输入。
- 延用稀疏命令与字段冲突检测，保留无关修改、时间设置和旧区域数据。编辑窗口不更改生成、预演或存储协议。
- 中英文 UI、帮助和双语 Skill 说明同步。窄屏改为四个横向分区，长文本独立滚动。
