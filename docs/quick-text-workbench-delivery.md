# 角色工作台快速文本

2026-10-10，本地预览实现；沿用 0.1.0 preview，未发布远程版本。

## 使用方式

角色工作台的“快速文本”与“画布”编辑同一份草稿。快速文本连续展示标题、说话者、NPC 正文、玩家选项及跳转，配置按钮打开现有条件和效果编辑器。搜索覆盖标题、正文、说话者和选项。

分支概览仅派生显示，不保存另一套节点位置。点击节点定位正文，“定位到画布”定位当前卡片；支持缩放、平移、适配和收起。正文修改不会重置概览相机。默认及条件开场仍由原配置维护。

在输入框中使用 Ctrl / Cmd Enter 新增对白，Ctrl / Cmd Shift Enter 添加当前卡片的玩家选项。新增卡片不会自动接入现有分支，需要明确设置跳转。保存后可从任意卡片启动现有 Python 试玩。

手机宽度初始收起概览，提供足够的编辑最低高度和工作区纵向滚动。模式切换直接定位当前正文。没有新增 Ink 语法或项目迁移。

## 数据边界

- 使用原有节点、选项和人物 ID；保留出场绑定、条件、效果和画布走线元数据。
- 保存继续使用稀疏 authorEntityCommands 和原冲突检测，失败保留草稿。
- 切换页面、出场及对白继续使用原保存／放弃／取消保护。
- 分支概览处理循环、汇合、条件开场和未连接卡片，不重排作者数据。
- 无新增后端契约、持久化版本或模型调用。
