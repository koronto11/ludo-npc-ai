# 更多资料编辑入口补全验收

日期：2026-10-07。接续 [编辑入口审查](../edit-entry-20261007/report.md)。

## 已完成

| 对象 | 编辑入口与内容 |
| --- | --- |
| 关卡 | 场景与锚点设置 → 更多资料：说明、标签 |
| 时间锚点 / 场景轨道 | 场景与锚点设置、轴节点菜单 → 编辑：说明、标签；两处操作同一稳定 ID |
| NPC 组 | 组设置 → 更多资料：说明、标签；只改名称或资料保留独立成员的出场区间和锚点 |
| 剧情事件 / 条件规则 | 剧情编排 → 更多资料：标签；原说明入口保留 |
| 世界事实 / 故事变量 | 剧情资料 → 更多资料：标签；原说明入口保留 |
| 对白 | 角色工作台或剧情资料 → 更多资料：对白说明、标签 |
| 非对话文本 | 剧情资料 → 更多资料：独立说明、标签；正文保持独立 |
| 旧预演记录 | 角色试玩记录或工程试玩记录详情 → 旧记录说明与备注 → 编辑记录资料：说明、标签、备注；随机种子只读 |

额外资料默认折叠，标签每行一条，保存时清理空白行。关联保存采用稳定 ID 和三方差异合并，保留后续无关编辑；同字段冲突保留当前输入并拒绝覆盖。关卡设置、轴节点、NPC 组与旧记录资料的关闭操作提供保存、不保存、继续编辑；剧情和对白继续使用原顶部导航保护。

NPC 组设置同时修复原来仅改组名也统一成员时间的问题：只有修改共同时间才统一时间并解除时间锚点；改变场景保留成员时间。冻结新版试玩记录不开放覆盖编辑。
