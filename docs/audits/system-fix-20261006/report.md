6. 工程试玩历史支持关卡、角色卡片和全部来源筛选，保留旧路径记录的明确标记、删除与恢复。角色面板只显示该人物的卡片和旧记录，提供工程历史入口。卡片记录从正确的角色工作台重新测试，不送入全局路径重放。
7. 修复动态记录数量标签、切换语言后的试玩反馈和世界编辑撤销标题。角色姓名、故事、台词和历史快照保持作者原文。
8. Markdown 人物交付包含关键、支线、背景角色定位；JSON 协议无需迁移。
9. 空白关卡页面提供世界、人物、关卡起步入口；关系属性面板移除重复的旧式对白测试，保留出场链接和角色工作台入口。
10. 同步中文、英文控制台帮助及离线指南。重新构建 Windows 文件夹预览包，核对包内 HTML、JS、CSS 与当前构建一致。
