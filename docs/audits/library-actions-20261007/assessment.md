# 左侧资料库操作菜单评估 — 2026-10-07

范围：当前本地项目左侧资料库。依据：本次实时截图 01-library-current.jpg、可见页面结构，以及 App.jsx 条目入口和后端命令校验。此轮只评估，没有实现菜单或执行删除。

1. 查看资料库：分组清楚，但条目没有显式管理操作；点击行为随对象类型和当前页面变化，编辑/定位意图不够明确。

建议保留单击进入，在实际资料条目右侧增加独立“更多”按钮。菜单动作按对象类型命名：

| 类型 | 核心动作 |
| --- | --- |
| 关卡 | 打开关卡画布、编辑关卡设置、删除关卡 |
| 地点/区域/阵营 | 编辑资料、查看使用位置、删除资料 |
| 人物 | 编辑人物档案、打开角色工作台、查看出场/关系、删除人物 |
| 剧情事件 | 编辑事件、定位所属关卡、删除事件 |
| 对白图 | 编辑/试玩对白、查看绑定出场、删除对白 |
| 非对白文本 | 编辑文本、查看使用位置、删除文本 |
| 世界底稿 | 编辑世界底稿、查看事实/变量；不提供删除整个世界 |

“角色”“故事事件”等集合标题可提供新建/管理动作，不能当成业务对象直接删除。

删除流程：更多→删除→一次明确确认弹窗（形成二次确认）；显示名称、对象类型、引用数和处理范围。使用中的资料应显示引用并先解决引用，不能静默级联删除。删除关卡说明关卡布局/出场安排的处理范围，共享人物与对白不随关卡自动删除。历史试玩和生成记录保持可查看。提供明确撤销入口和删除前恢复点。

定位到多处时显示使用位置列表，由用户选择；不存在位置时不显示一个无效跳转按钮。当前地点名“关卡1/关卡2”与关卡入口“第一关/第二关”易混淆，应在菜单使用“编辑地点资料”与“编辑关卡设置”等具体名称。

交互：鼠标经过或选中时显示更多按钮；触屏常显；键盘焦点可见，菜单支持 Enter/Escape，按钮具有对象名称的可访问标签。沿用暖炭色、铜色强调；删除位于分隔线下并使用危险色。第一版不增加复制、批量生成、批量移动等不必要项。

限制：当前项目没有人物、事件、对白和文本，因此这些菜单是基于现有入口/数据引用结构的建议；删除恢复能力和键盘/触屏菜单仍需实施后验证。
