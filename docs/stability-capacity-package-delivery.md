# 撤销恢复、容量与 Windows 体验包

2026-10-06。本批完善日常编辑恢复入口、较大工程的总览和导出，并更新文件夹式 Windows 体验包。

## 编辑撤销与恢复

顶部新增撤销/重做按钮，关卡工具栏接入同一会话记录。覆盖已提交的手工人物设定、世界底稿、关系、对白结构与布局、关卡安排、快速备注和控件宽度，以及模板创建产生的普通编辑命令。

输入框外可用 Ctrl Z、Ctrl Shift Z / Ctrl Y。输入框内保留原生文本快捷键；弹窗或未保存的编排开启时，全局撤销禁用。对白未保存内容仍用现有保存/放弃流程。

服务端保存最多 30 步、8 MB 的稀疏差异，按稳定 ID 恢复实体与嵌套节点，保留列表顺序。只比较并恢复涉及的字段，不回滚整份旧工程；后来添加的其他人物设定、生成记录与试玩记录不会被整份快照覆盖。多命令操作原子恢复，引用校验与项目修订仍生效。冲突或恢复后引用不成立时保留当前内容与撤销栈。

每次撤销/重做产生新的工程修订并自动保存；保存失败则保留服务中的修改，可再次保存。新手工编辑清空重做分支。缓存超限会清空会话栈，需使用文件备份恢复。

缓存属于运行中的服务会话，关闭工程、重新从磁盘载入、恢复备份或重启服务后会重置。草稿采用/拒绝、生成任务、试玩与分支记录、模板库归档、模型配置使用各自流程，不进入这份作者编辑栈。原人物分组专用撤销入口保留，其自身修改同样会被统一入口记录。

## 容量测量与优化

离线夹具按 100 / 500 / 1,500 人物构造，每人 1 次出场、1 份 4 节点对白和一段故事。打开校验、编辑保存、撤销、预演和两类文本导出各测 3 次，首次保存测 1 次。以下为本机复测中位数，不代表其他硬件或复杂条件工程的性能承诺；编辑保存包含本地存储调用，不包含浏览器网络往返。

| 人物 / 节点 | 工程文件大小 | 编辑并保存 | 预演 | CSV 导出 | 设计稿导出 |
| --- | --- | --- | --- | --- | --- |
| 100 / 400 | 0.45 MB | 86 ms | 见报告 | 11 ms | 1 ms |
| 500 / 2,000 | 2.24 MB | 460 ms | 见报告 | 63 ms | 5 ms |
| 1,500 / 6,000 | 6.72 MB | 1,920 ms | 222 ms | 185 ms | 15 ms |

优化前 1,500 人物的 CSV 和设计稿中位数分别约 782 ms、570 ms。导出改用人物、对白归属与出场绑定索引，移除逐对象重复扫描；既有下载夹具仍与结果逐字节一致。

人物总览新增每页 60 人的分页，出场与对白计数按一次遍历建立索引。搜索、筛选与「选中筛选结果」覆盖所有页；选择跨页保留。卡片按内容确定行高，短窗口中备注与操作按钮通过列表滚动完整显示。

浏览器实际打开 500 人物工程，验证首屏 60 张卡片、选择 500 人、搜索第 500 人、末页 20 张卡片与禁用下一页。此轮没有对 1,500 人物画布进行完整浏览器流畅度验收，也没有验证大量循环、嵌套条件、规则和并发生成的压力。1,500 人物编辑保存已接近 2 秒；整份工程的序列化与复制仍需后续优化。文件读取保持原有 20 MB 上限。

测量脚本：`scripts/verify-capacity.py`。原始数据见 [基线](verification/capacity-baseline.json) 与 [复测](verification/capacity-report.json)。

## Windows 体验包

文件夹位于 `release/mvp-preview/LudoNPC/`，保留整个文件夹并双击 `LudoNPC.exe`。包含本批前后端、模板、导出与使用说明，不需要用户自行安装 Python 或 Node.js。

启动器预先绑定本机 socket；默认端口占用时使用空闲端口，浏览器在服务准备完成后打开实际地址。显式指定端口冲突时给出提示并退出，不进入其他程序页面。服务仍只监听 `127.0.0.1`，本机会话与同源限制保留。没有复用或终止其他已运行进程，也没有自动在互相独立的服务间共享工程锁。

程序包运行数据与程序目录分开，位置与退出方法见 [Windows 使用说明](windows-preview-guide.md)。最终压缩包为 `release/mvp-preview/LudoNPC-mvp-20261006-final.zip`，包含完整 `LudoNPC` 目录及说明，CRC 与 SHA-256 已核验，见 [归档报告](verification/mvp-archive-report.json)。

本机真实程序包验收 27 项，另有既有本地文件回归 16 项，覆盖端口冲突、静态资源、工程编辑、撤销重做、模板归档恢复、三类导出、保存重启、备份恢复与目标文件不覆盖。脚本为 `scripts/verify-mvp-package.py` 和 `scripts/verify-package.py`；见 [本批程序包报告](verification/mvp-package-report.json) 与 [本地文件回归](verification/mvp-base-package-report.json)。
