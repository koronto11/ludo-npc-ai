# 未保存编辑与页面切换

“放弃未保存编排”移到对白画布上方，与保存状态并排显示，使用铜色边框、背景与撤销图标。

切换工作区、人物、出场场景或对白时，存在未保存编辑则停留在当前页面，在工作区顶部显示持续提示：不保存并跳转、保存并跳转、取消。取消和 Esc 保留当前输入。保存失败保留页面与草稿，并在顶部显示错误；保存过程中禁止重复处理或操作当前编辑区。

对白、剧情事件/规则、世界事实/变量、初始状态、关卡节点名称和草稿候选接入同一离开保护。候选保存仅保存草稿，不接受到正式工程。浏览器关闭或刷新仍使用浏览器自己的离开保护。

验证：44 项 Node 测试通过；前端构建与 diff 格式检查通过。实际浏览器验证了取消保留输入、不保存后切换对白、顶部放弃按钮、保存并跳转后 JSON 持久化、校验失败留在原页、剧情编辑的工作区切换、Esc 取消，以及 740px 窗口的全部操作按钮可见。保存测试使用独立本地项目副本，主体验项目未写入测试内容。
