# 本地模板与内容交付

2026-10-06。本批补齐常用模板、跨工程复用及导出预览，保留人物、出场与对白的原有联动。

## 入口与流程

- 左侧「模板」：人物设定模板、对白结构模板、我的模板与归档。内置 3 种人物起点和 3 种对白结构，不需要配置模型。
- 人物档案「保存为模板」：先保存档案，再把设定加入本机模板库。
- 角色工作台「保存结构模板」：先保存编排，再保存正文、选项与跳转结构。
- 顶部「导出」：选择格式与范围，生成预览，再下载。未提交的编排会先显示保存并跳转、放弃并跳转和取消选项。

使用人物模板创建新人物，不覆盖来源。使用对白模板必须选择所属人物，可选择具体出场；创建后自动进入编排，绑定的节点跟随这次出场的时间、场景与条件。复制后的对白、节点、选项使用新 ID，内部跳转与循环保持一致，原对白保留。

模板是可编辑的结构起点，不是模型生成结果。人物模板保留故事、性格、口吻、目标与底线，分组、认知、出场与保护标记不复制。对白模板不复制来源工程的条件、效果、条件开场或说话者引用；保存后的提示列出移除数量，使用时重新配置。

## 本地存储

自定义模板保存在应用数据目录的 `templates.json`，与工程文件分开，在同一本机应用内跨工程复用。开发预览使用 `.local-data/planning-preview/templates.json`，正式运行遵循原应用数据目录设置。

模板库支持 200 项、20 MB 文件上限，类型校验、原子写入、文件锁和版本冲突检查。自定义模板可归档、恢复；内置模板保留。写入失败或文件损坏会提示错误并保留原文件，不静默重置。

工程备份不包含独立模板库或模型配置。迁移整套本机模板时需另行复制 `templates.json`；本批未提供模板库导入、重命名或就地编辑界面。API Key 仍仅留在页面会话与请求内存。

## 导出格式与边界

| 格式 | 内容与用途 |
| --- | --- |
| 关卡设计稿 Markdown | 人物设定、出场安排、NPC 组、关系、对白节点与选项、剧情事件与规则；可选择关卡或全工程 |
| 对白表 CSV | 人物和说话者名称、正文、选项、跳转 ID、条件和效果 JSON、出场与场景绑定；可选择关卡或全工程 |
| 工程备份 JSON | 完整可重开的工程，包含布局、草稿、任务历史与试玩记录；始终导出全工程 |

设计稿与对白表只使用正式内容，不包含草稿、生成历史与试玩记录。设计稿明确标记全工程事实、变量、初始状态和非对话文本资料，它们不会按关卡过滤。作者秘密与剧情条件也会导出，因此这是策划交付文档。

CSV 使用 UTF-8 BOM、标准多行与引号转义，并处理表格公式前缀。它是交付表，不是 Unity/Godot 运行时适配器；程序仍需按游戏逻辑解释条件与效果。导出不会修改工程，不调用模型。
