# 第四批：模型任务与字段草稿审核

本批把生成与作者工程之间的审核环节接入 Python 和导演台。生成角色、人物故事、对话图或信件等文本时，先保存结构化候选；作者比较、编辑并接受字段后，正式工程才变化。沿用本地 JSON 和已选定的暖灰铜色界面。

入口：[本地导演台](http://127.0.0.1:4174/)。早期 Windows 包为 `release/LudoNPC/`，需保留整个文件夹。包可以自带运行库启动；本次在开发电脑上实际启动验收，尚未完成无开发环境的干净 Windows 验证。

[草稿差异与任务记录](https://github.com/koronto11/ludo-npc-ai/blob/e96ecb7f7670362fe95fbc83d8c9006085d77099/docs/screenshots/batch-4-draft-review.png)

## 已接入的流程

1. 新建/打开本地工程，先填写世界前提或规则。
2. 配置连接档案：自定义兼容接口地址、模型 ID、远程/本机模式、输出上限、超时和临时错误重试次数。多个档案可切换，最多 30 个。
3. 用一次小文本请求测试连接。流式和 JSON 模式默认关闭，由作者按接口能力启用；文本测试成功不等于结构生成必定成功。
4. 选择新对象，或给已有对象生成指定字段。每行一个新名称，每批 1–10 项；可选当前预演的时间、场景、选择轨迹和人物认知。
5. 任务保存排队/运行/逐项结果、草稿 ID、失败原因和实际返回用量。通过 SSE 更新进度，断线可回退查询。
6. 在草稿审核比较正式值与候选，修改并保存候选，再接受选中字段、拒绝，或原子接受所有未过期的待审核候选。
7. 审核后的对话和文本进入既有编排、时间线与预演；保存输入分支、重新打开文件和导出保持同一数据来源。

[生成对话的选项跳转](https://github.com/koronto11/ludo-npc-ai/blob/e96ecb7f7670362fe95fbc83d8c9006085d77099/docs/screenshots/batch-4-generated-dialogue.png)

## 数据与审核规则

正式内容、草稿与生成记录都在选定工程文件及工程旁的恢复点中。连接档案在本机应用配置目录；密钥仅留在页面会话及运行任务内存，刷新页面后需重新填写。项目格式仍是 v2，新增字段有默认值，旧 v2 文件可载入，v1 迁移流程继续保留。

每份草稿记录目标、创建/修改方式、生成时字段值、作者内容摘要与来源。世界、人物、事件、规则、对话、文本和初始状态变化会使旧草稿过期；布局、任务进度、草稿编辑与预演分支保存不会使作者摘要过期。工程修订号仍检查所有事务。过期后接受被后端拒绝，作者要显式“重新比较并更新基准”，再次查看当前值后采纳。

候选不能改写对象 ID、类型和确认标记。已确认字段的不同候选值不能经审核覆盖；生成表单先排除这些字段，后端再次检查。手动作者编辑仍可主动调整正式设定。接受只写入选中字段，其余候选保留在该次已审核记录中，不自动再次应用。新建对象必须满足完整实体要求，取消必要字段可能导致审核被拒绝。

批量接受是一个原子事务；任何草稿过期、引用无效、字段保护或并发冲突都阻止整批提交。保存候选只允许修改未审核草稿；已审核记录不能重新写回待审核，也不能用候选编辑绕过目标/基准校验。

## 协议、任务与边界

- 本批适配 **chat/completions 文本协议**；支持基础 URL 或完整路径、普通 JSON 响应、SSE 文本片段和可选 JSON 输出请求。其他协议、图片、工具调用与服务商专用参数未实现。兼容性需逐个有效接口验证。
- 全局最多 2 个提供方请求并发、10 个活跃任务，每个任务最多 10 项；单项输出配置 128–16384 token，超时 5–300 秒。上下文最多 100 个关联对象、100000 字符，引用目录最多 500 项；响应收集约 2 MB 上限。这些是保护边界，尚不是规模性能承诺。
- 上下文来自世界、当前角色及预演知识、关联对象和有限引用目录。完整未来事实不会作为“角色已知事实”加入；显式作者引用与资料名称仍可能包含秘密。条件/引用校验不等于自然语言泄密检查，作者仍需审核。预演未完整执行时阻止请求。
- 临时错误可配置 0–2 次自动重试，默认不自动重试；收到流式内容后不会再自动重发。授权错误、截断响应、非法 JSON、非法字段与引用会给出失败，不自动调用模型修复。
- 部分失败保留成功草稿，界面的“重试失败项”发出新的请求，仅包含失败项。相同运行中请求 ID 不重复发起；已持久化任务不因重启自动重新请求。
- 取消终止本机等待和排队，保留已完成草稿；无法保证服务商停止计费。中断任务在重开工程时标为“已中断”，不带密钥自动续跑。
- 用量只展示响应提供的 token 数，没有返回则不编造；不估算准确费用。本地协议夹具返回的是测试数字，不能视为真实模型用量。
- 工程不包含连接配置列表与密钥；后续 [多模型优化](model-config-management.md) 为新任务增加了配置名称、模型 ID、无认证信息的接口地址及用途快照；适配器错误不保存服务商原始错误正文，识别到当前密钥的输出会遮蔽。不会扫描作者自由文本猜测其他凭据，密钥输入应使用专用会话栏。
- 文件写入失败保留进程内结果并提示重试保存/另存；异常断电前尚未落盘的数据仍可能丢失。恢复点沿用第二批规则，不保证永久保留每次任务更新。
