# 中英文控制台与完整帮助交付

## 使用效果

控制台顶部选择「中文 / English」，即时切换菜单、工作区、画布控件、表单、审核、试玩、状态和已知系统提示。默认中文，语言偏好保存在本机应用目录的 settings.json；浏览器还保存一个本地回退值。连续切换按顺序保存，最后一次选择优先。切换不刷新项目、不重挂编辑器、不翻译作者的姓名、场景、故事、分组或对白，不改变模型生成语言。

帮助采用同一全局语言，包含 16 个对应章节：新建项目、工作区、世界、关卡、人物、关系、对白、NPC 组、剧情规则、模型、审核、试玩、文件、模板/导出、AI 协作、故障处理。支持章节目录、全文搜索、无结果提示和前后章阅读；窄窗口改为横向章节导航，正文独立滚动，关闭操作始终可见。

src/helpContent.js 是帮助内容的唯一来源。运行 node scripts/generate-help-guide.mjs 生成 docs/user-guide-zh.md 和 docs/user-guide-en.md；--check 校验同步。Windows 打包会校验并附带两份离线手册。

## 实现与兼容

- src/i18nCore.js、src/i18n.js、src/locales/ 提供代码文案、参数替换、组件订阅和已知提示翻译。参数中的作者内容保持原文。标签表只用于明确的代码元数据，枚举和值保持原样。
- PUT /api/workspace/preferences 仅接收 ui_language: zh/en；本机会话和同源保护保持生效。原子保存仅更新应用偏好，不修改模型配置、密钥、工程或作者修订。失败时保留内存旧设置并告知浏览器回退。
- 未知服务商错误保留原始说明，配合当前语言的错误提示；原生操作系统窗口可能遵循系统语言。这些来源不自动调用翻译模型。
- 作者创作与模型输出不因界面切换而改写。项目存储格式、旧工程、Skills、模型连接与 Windows DPAPI 密钥保持兼容。
