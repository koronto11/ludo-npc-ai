# 草稿审核收件箱改版

审核页使用独立卡片，正文不默认展开。待审核、已采用、已拒绝、生成失败和已删除分开显示，支持名称/正文搜索和批次筛选。每份草稿独立采用，不是多个候选中只能选一个。

点击卡片打开详情弹窗。正文优先显示；字段差异、确认保护、冲突和结构编辑收进高级编辑，审核提醒单独折叠。底部固定采用、拒绝和关闭操作。关闭有修改的弹窗时提供保存、放弃和取消。采用后的记录可定位正式内容；场景草稿保留场景入口。

失败请求未生成正文，因此单独显示失败原因。可以只重试该项或删除该项；运行中的任务不可删除失败项。批量采用有明确确认，排除已删除草稿并保持原有过期基准检查和确认字段保护。

删除记录采用本地 `editor.deleted_generation_entries` 标记，包含来源、任务/草稿 ID、失败项索引和删除时间。提供立即撤销与已删除分类恢复；重新打开项目仍保留标记。草稿、任务原始快照和已采用的正式对象保留。删除只改变编辑器数据，不改变作者指纹和内容版本；已删除草稿必须恢复后才能审核。场景内容的待审核计数也排除已删除草稿。

审核页隐藏与审核无关的属性面板和故事时间线，生成批次与进度默认折叠。其他工作区保留原来布局。
