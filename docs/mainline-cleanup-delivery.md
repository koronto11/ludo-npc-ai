# 主线整理与发布前回归

本轮将 NPCs AI Studio 0.1.0 preview 的现有创作工作台、中英文帮助/Skill 和 README 收拢到同一主线，清理已不参与当前产品运行的早期原型代码。

## 清理范围

- 移除 `src/project.js` 的 v1 JavaScript 示例模拟器、未引用的 `src/Timeline.jsx`、对应的旧原型测试及未引用的浏览器测试工程快照。
- 将旧浏览器存档键单独放入 `src/legacyProjectStorage.js`，保留用户显式导入与 Python 迁移。
- 删除前端对示例人物/事件 ID 的特殊分支、旧场景快照写入和对白覆盖逻辑；事件使用当前通用条件与效果编辑，删除使用现有引用检查与确认流程。
- `npm test` 自动发现当前所有前端测试，避免默认命令仅验证退休原型。
- 更新架构入口与后端介绍；批次交付文档作为历史证据保留。

旧来源文件在本机忽略目录 `.local-archive/mainline-cleanup-20261007/` 保留可恢复副本；不会进入 Git。用户业务工程、应用配置与密钥未参与源代码清理。

## 保留的兼容与分发资源

Python v1 迁移、迁移测试夹具、旧目录回退、稳定存储/MIME/协议标识及 `.ludo.json` 扩展名继续保留。中英文 Skill 的桥接脚本与 Schema 副本由打包脚本检查同步，是独立分发所需内容。当前规则不依赖内置故事 ID。
