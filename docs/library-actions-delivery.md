# 左侧资料库操作菜单

验证日期：2026-10-07。NPCs AI Studio 0.1.0 预览版，本地实现，未发布。

左侧关卡、世界资料、人物、剧情事件、对白和文本均有独立的 `…` 菜单。分类标题提供创建或管理入口，实际资料条目提供对应编辑、使用位置和删除入口。单击和拖入画布的行为保留。

使用位置只统计结构化引用，不将正文中的同名词当成引用。地点的不同场景轨道、人物的不同出场分别列出；点击会打开相应编辑器或定位并标记关卡轨道。人物可直接进入工作台和关系画布；有角色绑定的对白可进入编辑与试玩，未绑定对白进入资料编辑器。

删除先展示对象类型、名称、范围和引用。引用未解决时不能确认删除；草稿、生成历史和旧预演输入中的有效引用也受保护，隐藏这些记录不等于解除引用。服务端仍执行最终完整性校验。删除关卡只删除该关卡的轨道、锚点、组和出场，共享档案与对白保留；若有外部剧情范围或预演输入引用该关卡，需先处理。删除未使用人物会在同一事务中清理该人物的初始状态，且明确列入确认范围。冻结的历史试玩文本快照保留。

删除后支持即时撤销，也支持项目文件恢复点。撤销使用现有会话内 30 步 / 8 MB 的编辑日志；后续新编辑会移除旧的即时删除提示，避免该按钮误撤销其他修改。重新启动后的持久恢复使用项目备份。目标和引用在提交时重新检查，拒绝冲突，不强行覆盖其他窗口的修改。

菜单支持右键、键盘 ContextMenu / Shift+F10、方向键、Home/End、Escape 和焦点返回；触摸设备保持操作按钮可见。菜单限制在视口范围内，短屏可滚动。既有顶部未保存编辑保护同样用于菜单跳转。

中英文帮助新增资料库章节，用户指南和同版本中英文 Skill 包同步说明。关于页面的更新记录已补充本次实现。
