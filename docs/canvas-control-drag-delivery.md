# 关卡控件拖动改进

日期：2026-10-07。NPCs AI Studio 0.1.0 本地预览。

## 问题与行为

旧画布固定把事件、人物、NPC 组分别排在上、中、下。NPC 组拖动虽显示纵向位移，松开仅保存时间/场景，无法改变同场景中的上下位置。人物和事件没有纵向跟随预览。

现在三类控件共用可持久化的混合顺序。上下拖动出现插入线和目标场景边框；同场景排序、跨场景移动保留原有时间与锚点绑定。左右拖动且保持同一排序位置时调整时间；人物两端继续调整区间，组和事件的右边缘继续调整显示宽度。竖向手势中的轻微横向偏移不会改变时间。

所有控件纵向跟随指针并抬高显示层级。靠近滚动容器边缘自动滚动，位移计入滚动量。Esc、pointercancel、意外丢失指针捕获或普通卡片拖到画布外均取消。保存提交期间保留预览，应用服务器新布局后在绘制前移除偏移，避免卡片先弹回再跳过去。

实际测量卡片高度安排间距，避免 NPC 组展开、宽度变化或内容变多时遮住下方控件。隐藏时间横轴仍可排序。拖动后不误触事件编辑和人物选择；宽度手柄点击后可使用左右方向键。

## 数据边界

`editor.level_control_orders[level_id]` 保存稳定的 `appearance:` / `group:` / `event:` 控件键。类型化命令 `set_level_control_order` 校验关卡归属、重复引用和预期顺序，拒绝其他编辑造成的冲突。删除/解散控件或移除关卡清理对应排列。旧项目缺省保持原来的事件、人物、组排序。排序不进入作者哈希、模型上下文或预演，不使待审核草稿过期。

时间/场景变动与排序在一次原子事务中提交，使用同一个撤销/重做记录。组移动保留成员各自的偏移、时长及锚点。自动生成的项目/命令/OpenAPI Schema、示例与中英文 Skill Schema 已同步。中英文帮助已补充手势说明。
